# مشروع مصحفي — الإصدار 3.1.31

- `android/`: تطبيق أندرويد كامل، مع Java وملفات الواجهة والمصحف والخطوط والترجمات والكتب والاختبارات وخدمة التحدي. افتح هذا المجلد في Android Studio واتبع README داخله.
- `ios/`: تطبيق iPhone وiPad. يعرض نفس واجهة `android/assets` داخل غلاف Swift، ويُبنى ويُرفع لـ TestFlight من GitHub Actions بدون ماك. **ابدأ من `ios/README-AR.md`**.
- `website/`: كود الموقع وWorker، مع ملفات البناء والاختبارات. استخدم Node.js 22 أو أحدث ثم `npm test` و`npm run build`. اطلع على README و`.env.example` لإعداد الاستضافة والخدمات.

ملفات `.openai/hosting.json` تحتفظ بمعرّفات الاستضافة الحالية للمشروع. عند نشر نسخة مستقلة استخدم معرّفات وموارد استضافتك الخاصة.

استُبعدت مفاتيح التوقيع وكلمات مرورها، وحسابات خدمة Firebase الخاصة، وملفات البيئة السرية، وتاريخ Git، ومخرجات البناء وملفات APK القديمة. إعدادات العميل العامة والبيانات اللازمة للبناء مضمّنة. لا تتضمن الحزمة أسرار بيئة التشغيل المستضافة؛ تُضبط منفصلة لدى مزود الاستضافة.

تحتوي `FILE-MANIFEST.json` على بصمات SHA-256 للتحقق من الملفات.
