# تفسير الآية أثناء الاستماع — 3.0.34 (84)

يظهر نص التفسير الميسر المضمّن دون إنترنت تحت الآية ورقمها، دون بطاقة، بحد ثلاثة أسطر (سطران في الشاشات القصيرة). يتغير مع الآية، ويُوضح نطاق النص المشترك لآيات متجاورة حسب بيانات التفسير الحالية. خيار إخفاء/إظهار التفسير محفوظ على الجهاز.

«عرض التفسير كاملًا» يفتح نافذة قابلة للتمرير ويوقف التلاوة مؤقتًا. إغلاقها بزر العودة أو الإغلاق أو الرجوع النظامي يعيد الاستماع من موضع التوقف دون إعادة تشغيل السورة أو طلب seek. إذا كانت التلاوة متوقفة من الأصل تبقى متوقفة. الرجوع السريع ينتظر إقرار الإيقاف قبل الاستئناف مرة واحدة. الإيقاف النهائي، تغيّر السورة/القارئ، أو مغادرة قسم الاستماع يلغي الاستئناف التلقائي. إذا أغلقت النافذة في الخلفية ينتظر الاستئناف عودة التطبيق للواجهة. لا تتغير مواضع المصحف أو الختمة.

اختبارات المتصفح نجحت: النص لكل آية، التوقف/الاستئناف ونفس الموضع، توقف سابق، الرجوع، تأخر إقرار الإيقاف مع الإغلاق السريع، إلغاء الاستئناف بعد stop، خيار الإخفاء، فتح التفسير بلمسة واحدة عندما أدوات المشغل مخفية، نص طويل، عرض 320/393/740/1280 والوضعان الفاتح والداكن. اجتازت اختبارات تزامن الآيات ومنع تراكبها وإخفاء أدوات المشغل والمزامنة التلقائية. لم يتغير محرك الصوت الأصلي في هذا الإصدار؛ استمرار الموضع يستخدم pause/resume الموجودين.
