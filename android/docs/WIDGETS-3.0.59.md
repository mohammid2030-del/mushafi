# Mushafi 3.0.59 (109): native home screen widgets

Three Android AppWidget providers: next prayer with five daily times; weekday with Hijri and Gregorian dates; daily verse or remembrance. Original petrol, ivory and muted gold styling, rounded cards and optional transparent background. Seven complete Quran verses and three existing adhkar rotate by local date; exact Arabic/English texts and references are verified against existing application sources by verifyWidgetTexts. No Quran, tafsir, audio catalog or timing data changes.

More → Home screen widgets opens a native gallery. Supported launchers offer Add to home screen; all launchers can use long press → Widgets → Mushafi. Each instance supports independent night/light/transparent background, follow-app/Arabic/English language, and verse/remembrance content. Configuration preview is temporary; only Save commits. Widget resize limits preserve legibility. Native widget picker previews are captured from Android RemoteViews rendering.

Prayer widgets use PrayerSettings and PrayerCalculator unchanged, including method, Asr, offsets, Ramadan, coordinates and timezone. With no confirmed saved location they ask the reader to open Mushafi, rather than silently showing Riyadh defaults. No background GPS, network calls, account fields or location permission requests are added. Foreground location/settings changes refresh widgets. Clock/date/timezone/locale/boot/package-replacement and standard platform widget updates refresh them independently of the WebView. Last saved coordinates continue to apply until the app obtains a fresh location.

The native Chronometer counts down on Android 7+ when the existing precise-alarm authorization is available; otherwise the exact next prayer time remains displayed. Refresh at prayer boundaries uses existing exact alarm access when allowed, inexact fallback otherwise; no new permission prompt. Platform update fallback is 30 minutes. System/OEM battery restrictions and force stop can delay updates. No per-second app worker, foreground service, or wake lock. Deleting the last widget cancels its alarm and per-widget options are removed.

Hijri uses Android Umm al-Qura on API 24+, with an explicitly labeled civil calculation on API 23. Gregorian and daily content follow device timezone; prayer times follow the application's saved prayer timezone. Widgets are home-screen widgets; lock-screen placement depends on the launcher/OS and is not promised.

QA: real API 29 AppWidgetHost binding for all three providers; native RemoteViews rendering at 180/300/520 widths, both languages and three backgrounds; exact prayer boundaries and tomorrow's Fajr after Isha; independent instance options; actual configuration Cancel/Save; daily rotation and canonical text; unconfigured location; deletion cleanup. Native per-widget bitmap previews inspected. Release build and all six data gates required. Physical OEM launcher and API 23 execution are not part of this local test.
